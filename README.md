# All-in-One THC Grow

Status: **archive-ready legacy placeholder / not deployable**.

This repository does not currently contain an application. The functionality originally associated with an all-in-one cultivation system is now better represented by the active DTF repositories:

- `dtfgenetics/Thc` → **THC GrowLens** for local-first cultivation records, environmental tools, observations, reporting, and optional account sync.
- `dtfgenetics/thc-grow-hub` → **Teaching Healthy Cultivation Grow Hub** for academy, encyclopedia, SOPs, glossary, downloads, sources, and structured education.
- `dtfgenetics/Thc-dataset` → **THC Grow Doc** for plant-health evidence screening and diagnostic reference data.

Do not deploy this empty repository as another public app. New functionality should be added to the correct canonical product unless a genuinely distinct product is approved first.
